# The Lyrics Party

A responsive music lyrics website featuring "This Must Be the Place (Naive Melody)" by Talking Heads.

## Project Overview

This project was created for the Web and Internet Fundamentals course at Bow Valley College.

## Features

- Responsive webpage layout
- Custom CSS styling
- Navigation bar and song information banner
- Formatted verses and choruses
- Song information sidebar
- Album artwork and background image

## Technologies Used

- HTML5 (provided starter file)
- CSS3
- GitHub Pages

## Project Requirements

The original HTML structure was preserved. All visual styling was implemented using the external `styles.css` file without JavaScript.
